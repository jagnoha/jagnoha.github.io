02 / Engineering architecture

Product interactions stay separate from business logic.

The application uses a workspace-based monorepo with a Next.js frontend, a domain-oriented NestJS API, and a separate worker for asynchronous processing.

PostgreSQL and Supabase services provide the durable data and access layer, while provider integrations remain behind backend boundaries.

03 / Engineering highlights

Automation built around review and control.

The design treats AI output and external provider responses as inputs to validate, not as authority to change marketplace state.

01Featured control

Human-in-the-loop automation

Copilot groups related issues, supports configurable rules, and presents proposed changes for review before they reach live listings.

02

AI-assisted listing workflows

Structured listing generation from product images combines content generation, field validation, pricing guidance, and asynchronous processing.

03

External platform integrations

Backend services coordinate eBay OAuth, account connections, seller policies, listing publishing, and relisting workflows.

04

Security and data isolation

Encrypted eBay token storage, server-side provider credentials, Row-Level Security, and owner-scoped controls protect seller data and accounts.

05

Operational reliability

Background workers, job tracking and retries, health monitoring, and cached image-cleanup results address external failures and redundant provider costs.

04 / Technical challenges

Design decisions at system boundaries.

  • Marketplace constraintsCoordinate probabilistic AI-generated content with eBay’s strict category, field, policy, and publishing requirements.
  • Reviewable automationKeep potentially risky changes visible and reversible through grouped recommendations and preview-first workflows.
  • Async failure handlingTrack long-running jobs, retries, and external API failures without tying processing to a browser request.
  • Connected-account securityProtect seller data, OAuth tokens, and provider credentials while enforcing owner-scoped access.
  • Clear application boundariesSeparate frontend interactions from backend business rules, provider orchestration, and durable data access.

Functional application in private preview

Metoras is a working SaaS application currently available through a controlled private preview. The platform includes functional listing creation, marketplace integrations, listing analysis, and AI-assisted automation workflows.
