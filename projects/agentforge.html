AgentForge

A private, local-first engineering CLI in active development. Its implemented components turn agent attempts into inspectable evidence while keeping review, approval, and publication behind separate boundaries.

01 / Engineering problem

Agent output is not engineering evidence.

A successful model response does not prove that a repository is safe to change, a test suite passed against the resulting revision, a reviewer approved the exact artifact, or a remote write is authorized.

AgentForge makes those distinctions durable. Tasks, attempts, revisions, validation checks, review packages, approvals, and publication records are modeled separately so one successful step cannot silently stand in for the next.

02 / Implemented components

Guarded at every transition.

Core policy and SQLite persistence enforce the modeled lifecycle boundaries. A generic status caller cannot jump into review or completion: current-revision validation and matching approval evidence are required at the relevant transitions. These verified components do not imply that the complete issue-to-PR workflow is production-ready.

  1. 01Task + worktreePersist scope; verify owned Git workspace
  2. 02Bounded executionOne durable attempt with explicit outcomes
  3. 03Revision validationTrusted profile + before/after fingerprint
  4. 04Review packageBind task, tree, checks, and provenance
  5. 05Human authorizationExact controlling-terminal challenge
  6. 06Draft PR publicationApproved snapshot only; never merge

04 / Security boundaries

Fail closed when evidence is uncertain.

  • Execution is not validation.A zero exit and final message do not create test evidence or approval.
  • Validation is not approval.Passing checks do not complete a run or authorize GitHub mutation.
  • Approval binds an exact snapshot.Changed credentials, repository evidence, metadata, or review artifacts stop publication.
  • Timeout is not failure proof.Ambiguous pushes and PR creation enter reconciliation instead of being retried blindly.

Private development status

AgentForge is not publicly released, and no public demo or source repository is available. The private source implements and tests the components described above, but this portfolio review did not reproduce the complete issue-to-PR workflow on its qualified Ubuntu/Codex/GitHub runtime. This case study does not claim production readiness, autonomous merging, a hosted multi-user service, or commercial deployment.
